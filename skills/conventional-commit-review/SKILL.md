# Conventional Commit Review

- Formato: `<type>(<scope>): <subject>`
- Tipos autorizados: `feat`, `fix`, `test`, `refactor`, `docs`, `chore`, `style`.
- Modo imperativo en minúsculas, sin punto final.
- Scope vinculado al módulo modificado (ej: `validation`, `ui`, `db`, `actions`).
